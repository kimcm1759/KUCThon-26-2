# 소리 파일 넣는 법

```
public/sounds/<물건>/<연장>/<이벤트>.mp3
```

- **물건:** `laptop`(노트북) · `book`(책) · `can`(캔 음료) · `_common`(공통)
- **연장:** `hammer` · `bat` · `press` · `laser` · `bomb` · `debris`(떨어지는 파편)
- **이벤트:** 아래 표의 이름을 그대로 써요. 모두 소문자예요.

물건 폴더에 파일이 없으면 `_common/<연장>/`의 같은 이름 파일을 써요. 둘 다 없으면 소리 없이 넘어가요. 그래서 모든 파일을 한 번에 채울 필요는 없어요.

**변형:** `hit.mp3`, `hit_2.mp3`, `hit_3.mp3`처럼 번호를 붙이면 칠 때마다 무작위로 골라요. 음높이도 살짝 바뀌어서, 같은 소리가 반복돼도 덜 어색해요.

**적용:** 파일을 넣은 뒤 `npm run sounds`를 실행하거나 개발 서버를 다시 켜면 반영돼요.

## 화면 보면서 타이밍 맞추기

부수기 화면 주소 끝에 `?sync`를 붙이면 (예: `http://localhost:3000/jobs/mw51k9ky-49374c/play?sync`) 위에 **소리 맞추기** 패널이 떠요. 설정 → 개발자 화면의 "소리 맞추기" 버튼으로도 갈 수 있어요.

- 소리가 날 때마다 `0.512s  hammer/hit  laptop/hammer/hit.mp3`처럼 한 줄씩 찍혀요. 시간은 그 테이크의 첫 소리부터 잰 값이고, 2.5초 동안 아무 소리도 없으면 새 테이크로 0부터 다시 재요.
- 파일이 있으면 연두색으로 실제 재생되는 파일, 없으면 빨간색으로 **넣어야 할 경로**가 나와요.
- 없는 소리는 대신 "삐" 소리가 나요 (이벤트마다 음높이가 달라요, 🔁 루프는 "웅" 소리). 화면이랑 박자가 맞는지 귀로 먼저 확인할 수 있어요. 패널의 체크박스로 끌 수 있어요.
- **복사**를 누르면 지금 테이크의 목록이 탭으로 구분된 글로 복사돼요 (스프레드시트에 붙여넣기 가능).
- 오른쪽 위 소리 선택에서 노트북·책·캔 세트를 바꿔 들어볼 수 있어요.

새 파일을 넣었으면 `npm run sounds`를 실행하고 화면을 새로고침하면 돼요 (서버 재시작 필요 없음).

### 다른 컴퓨터에서 처음 볼 때

```
git pull
cd web
npm install
npm run dev
```

그다음 http://localhost:3000 → 게스트로 로그인 → 설정 → 개발자 화면 → 원하는 물건의 "소리 맞추기". API 키(`.env.local`)는 없어도 돼요. 이미 만들어진 노트북·캔·머그컵이 `.data/`에 들어 있어서 사진 찍기만 안 될 뿐 부수기는 다 돼요.

## 이벤트 목록 (초안 · 소리 담당 확정 후 바뀔 수 있어요)

🔁 = 반복 재생(루프)용이라 앞뒤가 자연스럽게 이어져야 해요. **추천 위치**가 "물건별"이면 노트북/책/캔에서 소리가 달라야 하는 것, "공통"이면 `_common`에 하나만 있어도 되는 것이에요.

| 연장 | 이벤트 | 언제 | 추천 위치 |
|---|---|---|---|
| hammer | `swing` | 망치를 휘두르기 시작할 때 | 공통 |
| hammer | `hit` | 맞는 순간 (매번) | 물건별 |
| hammer | `damage` | 맞았지만 아직 안 깨졌을 때 (금 가거나 찌그러짐) | 물건별 |
| hammer | `break` | 깨지는 순간 | 물건별 |
| bat | `swing` | 휘두르기 시작 | 공통 |
| bat | `hit` | 맞는 순간 — **알루미늄 배트 "깡"** | 공통 또는 물건별 |
| bat | `damage` | 맞았지만 안 깨졌을 때 | 물건별 |
| bat | `knock` | 맞고 옆으로 밀려날 때 (책상 긁힘) | 공통 |
| bat | `break` | 깨지는 순간 | 물건별 |
| press | `motor` 🔁 | 프레스가 움직이는 동안 (유압 모터) | 공통 |
| press | `contact` | 판이 물건에 처음 닿을 때 | 물건별 |
| press | `crush` 🔁 | 누르는 동안 (눌릴수록 커져요) | 물건별 |
| press | `burst` | 눌리다 터질 때 (노트북·책) | 물건별 |
| press | `crunch` | 끝까지 납작해졌을 때 (**캔은 터지지 않고 이걸로 끝나요**) | 물건별 |
| press | `release` | 판이 다시 올라갈 때 ("치익") | 공통 |
| laser | `start` | 레이저 켜질 때 | 공통 |
| laser | `beam` 🔁 | 빔이 나가는 동안 | 공통 |
| laser | `burn` 🔁 | 빔이 물건에 닿아 있는 동안 (지글지글) | 물건별 |
| laser | `cut` | 한 번 잘릴 때마다 | 물건별 |
| laser | `end` | 레이저 꺼질 때 | 공통 |
| bomb | `place` | 폭탄을 놓을 때 | 공통 |
| bomb | `fuse` 🔁 | 도화선 타는 1.6초 동안 | 공통 |
| bomb | `explode` | 폭발 | 공통 |
| debris | `small` | 작은 조각이 책상에 떨어질 때 (찰랑, 툭) | 물건별 |
| debris | `large` | 큰 덩어리가 떨어질 때 (쿵) | 물건별 |
| finish | `ding` | 물건이 깨진 상태(BROKEN!)가 되면 0.9초 뒤 한 번 (싱잉볼 "띵") | 공통 |

## 파일 형식
- mp3(권장) 또는 ogg/wav/m4a
- 짧게 자르기: 앞 무음 없이 바로 시작
- 음량 맞추기: 피크 -1dB 정도
- 모노도 괜찮아요
- 🔁 파일은 끝과 처음이 끊김 없이 이어지게 다듬어 주세요

## 최소 세트 (이것만 있어도 시연 가능)
- `_common`: `hammer/swing`, `bat/hit`, `press/motor`, `laser/beam`, `bomb/fuse`, `bomb/explode`
- 노트북·책·캔 각각: `hammer/hit`, `hammer/break`, `press/crush`, `press/burst`(캔은 `press/crunch`), `laser/cut`, `debris/small`
